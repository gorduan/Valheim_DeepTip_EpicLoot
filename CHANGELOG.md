# Changelog

## 1.0.0

- First version: every EpicLoot magic effect explained in German and English, checked against EpicLoot's code
  (0.15.5 did not change any effect), with its value range per rarity, where it can appear and which effects exclude it,
  built from the definitions the game has loaded (also the server's config).
- Every effect line of an EpicLoot tooltip links to its explanation, also the starred rare effects that shimmer.
- General terms: rarity, stars, roll range, number of effects, shard slots, runes, sets, legendary and mythic items,
  identifying, the enchanting table and its tabs, enchanting materials.
